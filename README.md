# 하늘을 닦는 사람들 · SkyWorker

두 플레이어가 고층 건물의 곤돌라에 함께 올라 유리창을 청소하는 **PC VR 직업 체험 시뮬레이션**입니다. 연습 창문에서 물을 뿌리고 닦는 순서를 익힌 뒤 곤돌라에 탑승합니다. 작업 중에는 손목 시계로 진행 상황을 확인하고, 작업이 끝나면 곤돌라에서 소요 시간과 임금 등급을 확인합니다.

## 담당 기능과 코드

### 1. 튜토리얼: 분사와 닦기를 각각 확인하는 연습 창문

튜토리얼 존의 안내 UI와 바닥 표식으로 안전 수칙과 조작 순서를 안내했습니다. 연습 창문에서는 **물을 다 뿌린 상태와 청소가 끝난 상태를 구분**해야 합니다. 그래서 먼지의 분사 진행률과 물자국의 닦기 진행률을 따로 계산해 위젯에 전달했습니다. 두 값이 모두 100%일 때만 초기화를 예약해 다음 연습을 준비합니다.

[두 진행률 계산과 위젯 갱신](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/VR_PracticeWindowUIActor.cpp#L100-L192) · [완료 조건과 초기화 예약](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/VR_PracticeWindowUIActor.cpp#L233-L264)

### 2. 곤돌라: 탑승 인원 확인과 층간 이동

탑승장에서는 현재 인원과 필요 인원을 표시합니다. 출발 버튼을 누른 사람이 탑승 구역 안에 있고 필요 인원이 모두 모였을 때만 작업 레벨로 이동합니다. 출발 요청을 수락하면 로딩 안내로 바꾸고 중복 요청을 막습니다.

작업 중 상하 버튼을 누르면 목표 층의 높이를 계산합니다. 이동하는 동안에는 버튼 충돌을 끄고, 곤돌라가 이번 프레임에 움직인 높이만큼 탑승자도 함께 이동시킵니다. 목표 층에 도착하면 버튼을 다시 사용할 수 있습니다.

[탑승 인원 표시와 출발 조건](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/GondolaBoardingStation.cpp#L157-L271) · [곤돌라와 탑승자 이동](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/Gondola.cpp#L119-L182) · [버튼 잠금과 목표 층 계산](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/Gondola.cpp#L276-L331)

### 3. 손목 시계: 작업 화면을 떠나지 않고 진행 상황 확인

손목을 들어 **청소 진행률·현재 구역·경과 시간**을 확인하도록 구성했습니다. 캐릭터의 워치 갱신 함수는 공유 작업 상태인 `ASkyGameState`에서 분사·닦기 진행률을 읽어 각각 50%씩 반영하고, 곤돌라 층을 구역명으로 변환합니다. 위젯은 이 값을 진행 막대·백분율·분:초로 표시합니다.

[작업 상태를 워치에 전달 · 캐릭터 연동 구간](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/VRPlayerCharacter.cpp#L818-L831) · [워치 위젯의 표시 형식](Private/VR_WorkWatchWidget.cpp)

### 4. 작업 결과: 청소 완료 판정에서 등급 표시까지

작업 대상이 하나 이상이고 **분사와 닦기 모두 목표 개수에 도달**하면 완료 상태로 전환합니다. 이때 경과 시간 타이머를 멈추고 임금과 소요 시간을 곤돌라의 결과 위젯에 전달합니다. 위젯은 임금을 기준으로 등급을 표시합니다(A: 70만 이상, B: 65만 이상, C: 60만 이상, 그 미만: F). 종료 버튼은 팀의 타이틀 복귀 처리와 연결됩니다.

[작업 완료 조건과 결과 전달 · 게임 모드 연동 구간](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/SkyGameModeBase.cpp#L42-L116) · [곤돌라 결과 화면 표시](https://github.com/Gdongu/SkyWorker/blob/32d67a3a57e897e9836564d9a01f73b446db0e8e/Private/Gondola.cpp#L246-L274) · [등급 계산과 종료 버튼](Private/VR_WorkCompleteWidget.cpp)

### 5. 전체 UI와 레벨 동선

로비·튜토리얼·작업 안내·경고·결과 UI를 제작하고 표시 조건을 게임 진행에 연결했습니다. 연습 중에는 창문 옆에서 두 작업의 진행률을, 출발 전에는 탑승장에서 인원수를, 본작업 중에는 손목에서 진행 상황을 확인하도록 정보의 위치를 나눴습니다. 레벨은 연습 구역에서 탑승장, 실제 작업 위치로 이어지는 동선으로 구성했습니다.

## 팀 작업과 회고

팀장으로서 작업물 병합과 일정 조율을 맡았습니다. 기능을 통합하면서 특히 중요했던 것은 **도구가 판단하는 완료와 UI가 표시하는 완료의 기준을 맞추는 일**이었습니다. 연습 창문은 분사와 닦기를 따로 보여주고, 손목 시계는 두 값을 하나로 요약하며, 결과 화면은 두 작업이 모두 끝났을 때 열립니다.

다음 VR 프로젝트에서는 개발 초기부터 팀원들이 실제 기기를 번갈아 착용해 확인하는 시간을 일정에 넣고 싶습니다. 한 명이 곤돌라를 조작하는 동안 다른 한 명은 자신의 손목에 같은 작업 상태가 보이는지 확인하고, 역할을 바꿔 버튼 접근성과 글자 가독성을 점검하는 방식입니다.
